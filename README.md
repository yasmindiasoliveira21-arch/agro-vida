# 🌾 AgroTech - Agricultura Sustentável

> Projeto desenvolvido durante o curso de Desenvolvimento Web Front-end da [Alura](https://www.alura.com.br/).

## 📝 Descrição
O **AgroTech** é uma landing page moderna focada na apresentação de soluções tecnológicas voltadas para a agricultura de precisão e sustentabilidade no campo.

## 🚀 Tecnologias Utilizadas
- **HTML5**: Estruturação semântica do projeto.
- **CSS3**: Estilização com variáveis e layout responsivo (Flexbox).
- **JavaScript**: Manipulação do DOM e navegação suave.

## 📂 Estrutura de Arquivos
- `index.html` - Página principal da aplicação.
- `css/` - Arquivos de estilização.
- `js/` - Scripts de interatividade.
- `assets/` - Imagens e ícones.
